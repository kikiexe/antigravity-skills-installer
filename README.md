### Antigravity Tools Sync

Otomasi setup tools dan skill token saver Antigravity (Linux, macOS, Windows)

### Tools

1. [anti-slop](https://github.com/miqdadbadjuber/anti-slop): Filter pembersih komentar kode dan boilerplate AI generik.
2. [ponytail](https://github.com/DietrichGebert/ponytail): Penegak prinsip minimal code ladder untuk reduksi ukuran diff dan konsumsi token.
3. [graphify](https://github.com/Graphify-Labs/graphify): Codebase knowledge graph untuk navigasi kontekstual (CLI dan MCP server).
4. [rtk](https://github.com/rtk-ai/rtk): Runtime token compressor untuk memotong output terminal yang berisik.
5. [codegraph](https://github.com/colbymchenry/codegraph): AST syntax tree traversal dan symbol call path explorer (CLI dan MCP server).
6. [context7](https://github.com/upstash/context7): Fetcher dokumentasi resmi library via MCP.
7. [Understand-Anything](https://github.com/Egonex-AI/Understand-Anything): Visualizer struktur codebase interaktif.
8. [caveman](https://github.com/JuliusBrussee/caveman): Mode komunikasi ultra-ringkas untuk memotong konsumsi token obrolan hingga 75%.

### Cara Pakai

Linux, macOS, atau Windows Git Bash
Untuk clone dan setup lengkap:
```bash
chmod +x install.sh config.bash
./install.sh
```
Untuk refresh konfigurasi saja (tanpa re-clone):
```bash
./config.bash
```

### Windows PowerShell
Untuk clone dan setup lengkap:
```powershell
.\install.ps1
```
Untuk refresh konfigurasi saja (tanpa re-clone):
```powershell
.\config.ps1
```
